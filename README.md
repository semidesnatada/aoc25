### Advent of Code 2025

The code in this repository solves all 12 Advent of Code challenges for 2025.

#### Instructions

>> Place your puzzle inputs in csv files in a folder in the project root called "inputs". The functions also expect one *test* puzzle input per day, except day 11 which expects 2 (one for each part).

>> Each day's input should be labelled "day_X.csv". Each day's test puzzle input should be "day_X_test.csv". (Day 11's second input should be day_11_test_p2.csv)

>> Call the function day_X() to solve a given day.

>> Call the function all_days() to solve all days sequentially.

Note: X should contain a leading 0 for single digit days (so day_01.csv, day_01())

#### Notes to the puzzles

1. Day 10 requires solving Diophantine equations, and finding the solution with the solution with minimum sum. To implement this solution I used a third party linear programming solver, rather than build my own. If I get time, I may try to implement my own simple solver to remove this dependency.

2. My day 12 solution will not solve a general puzzle input for the type of problem (though from online forums it appears that all other puzzle inputs generated by AoC could be solved by my technique). I rely on the fact that the puzzle input only includes cases which either obviously pass or obviously fail. Under the rules stated in the problem, it is technically possible to create a puzzle input which my function would not correctly solve. A more general solution is a lot more difficult and I likely won't bother trying to implement one!
